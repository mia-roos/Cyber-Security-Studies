### Exploring Debian Linux and Virtualisation

I downloaded the **Debian 13 Trixie Live Xfce** ISO image and installed Debian in an **Oracle VirtualBox** virtual machine on my Windows computer.

The installation was not entirely straightforward. I encountered graphics-related startup errors and experimented with VirtualBox display settings. After troubleshooting, I was able to start Debian, log in to the Xfce desktop and open the terminal.

I used the following command to verify the operating system:

```bash
cat /etc/os-release
```

The output confirmed **Debian GNU/Linux 13 (trixie)**, version **13.7**.

This exercise helped me understand the difference between the host operating system, virtualisation software and the guest operating system. It also showed me that troubleshooting is an important part of technical learning.
