## What I learned

### GitHub and version control

- A repository stores files and their revision history.
- A commit records changes to the repository.
- A commit message describes what changed.
- README.md introduces the repository and can serve as the
  homepage of a GitHub Pages site.

### Markdown

I practised creating headings, paragraphs, lists, and links.
I learned that the .md file extension allows GitHub to recognise
and display Markdown formatting.

I also learned to create a relative link between files:

[h0 – Create a web page](../cybersecurity-in-healthcare.md)

The ../ means that the linked file is one folder above this
diary entry.

### GitHub Pages

I learned the difference between my GitHub profile, a repository,
and a published website.

My profile introduces my GitHub account. The repository contains
the source files. GitHub Pages turns those files into a website
that others can read in a browser.

### Cybersecurity in healthcare

I explored how cybersecurity connects with patient safety,
healthcare professionals' work, and continuity of care.

Practical security measures include using personal credentials
securely, enabling multi-factor authentication, locking
workstations, recognising phishing, and reporting incidents.

I also identified a systematic review by Nifakos and colleagues
as a relevant source on human factors in healthcare cybersecurity.

## Challenges and solutions

At first, I was unsure whether the learning diary required
a new project or repository. I learned that I can organise
diary entries in a folder within my existing repository.

My first assignment file initially had no .md extension.
After adding the extension, GitHub displayed its headings
and paragraphs correctly.

I also discovered that changing the repository name and
description does not automatically change the text in README.md.
These need to be edited separately.

## My reflection

The most rewarding moment was seeing my work published
as a website. GitHub became easier to understand when I used it
to create something connected to my own interests.

My healthcare background gives me a useful perspective on
cybersecurity. I want to understand both the technical issues
and the human and organisational factors that affect safe care.
